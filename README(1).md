# RTV Laptops Landing Page

Landing page responsive para RTV Laptops.

## Archivos

- `index.html`: página completa con HTML y CSS integrado.
- `assets/logo-rtv-laptops.png`: logotipo usado por la landing.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube `index.html`, `README.md` y la carpeta `assets`.
3. Ve a **Settings > Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige la rama **main** y la carpeta **/(root)**.
6. Guarda los cambios.
7. Espera unos minutos y abre la URL publicada por GitHub Pages.
